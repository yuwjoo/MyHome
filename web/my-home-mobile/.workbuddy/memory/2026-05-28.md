## Bug 修复

- **DeviceCard 开关错位**：将开关从 `absolute top-3 right-3` 改为 flex 布局顶部行（`flex items-start justify-between`），图标左 / 开关右，彻底消除绝对定位偏差问题。
- **底部弹出层滚动穿透**：所有底部弹出层（BottomSheet / AddSheet / FileActionSheet / CategoryPicker）打开时锁定 `document.body.style.overflow = 'hidden'`，遮罩加 `@touchmove.prevent` 阻止触摸穿透，关闭后恢复。
- **FileActionSheet 双 script 块合并**：原有两个 `<script>` 块（setup + lang="ts"），合并为单个 `<script setup>`。
- **多选模式下禁用下拉刷新**：`usePullRefresh` 新增可选 `disabled` ref 参数，FilesView 传入 `isSelecting` 确保多选时不会误触下拉刷新。
