## 目录设计

### 目录分类

目录分类有两个维度：**作用**决定目录的结构形态与对外入口，**范围**决定目录内代码的可见范围

#### 按作用分类

| 分类                                   | 说明                                                                                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 普通目录                               | 存放任意的代码文件；可有任意个文件/目录；外部文件可以访问任意文件/目录                                                                                        |
| 模块目录（建议目录名称为复数，不强制） | 存放一组同类型/功能的代码文件；可以有任意个功能文件/目录，任意个普通目录，需要在整个模块目录复用的文件放`common`目录中（可选）；外部文件只能访问功能文件/目录 |
| 功能目录                               | 存放一种功能/特性的代码文件；必然有且仅有一个`index`入口文件供外部文件访问；外部文件只能访问`index`文件                                                       |

#### 按范围分类

| 分类                                   | 说明                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| 区域目录（不特别说明时，默认区域目录） | 存放当前区域的代码文件；只可被当前所处区域（父目录树）中的文件访问，不限层级 |
| 全局目录                               | 存放全局公共代码文件；任意位置的文件都可以访问到，不受任何上级目录的规范约束 |

### 基础目录

基础目录本身没有功能目录：功能目录是业务落地处的形态（如 `modules/publish/modules/manifest/`），按其自身结构判定作用分类。

| 目录       | 分类               | 说明                         |
| ---------- | ------------------ | ---------------------------- |
| `modules/` | 模块目录           | 存放模块化后的代码           |
| `common/`  | 普通目录           | 存放当前区域的公共代码       |
| `utils/`   | 模块目录           | 存放纯逻辑、无副作用工具代码 |
| `types/`   | 普通目录，全局目录 | 存放ts类型代码               |
| `assets/`  | 普通目录，全局目录 | 存放静态资源                 |
| `hooks/`   | 模块目录           | 存放web端vue hook代码        |
| `doc/`     | 普通目录，全局目录 | 存放当前域的文档             |

### 分层目录

`src/` 下按 Electron 三端 + 共享层划分：跨层访问只允许按下表进行，禁止反向依赖

| 目录        | 作用                         | 能访问的层         | 被哪些层访问                     |
| ----------- | ---------------------------- | ------------------ | -------------------------------- |
| `main/`     | 存放Electron主进程代码文件   | `shared/`          | `preload/`                       |
| `preload/`  | 存放预加载脚本代码文件       | `shared/`，`main/` | 无                               |
| `renderer/` | 存放Electron渲染进程代码文件 | `shared/`          | 无                               |
| `shared/`   | 存放共享给所有层的代码文件   | 无                 | `main/`、`preload/`、`renderer/` |

### 项目结构

目录为**设计基准**：新增 / 重命名 / 迁移目录前须对照下图，实际落地演进以此为准。

```text
src/
├── main/                 # 主进程（桌面层）
│   ├── modules/          # 所有业务能力模块
│   │   ├── ipc/          # IPC通道监听/发送
│   │   ├── window/       # 窗口处理
│   │   ├── ...
│   ├── stores/           # 所有本地持久化仓库
│   ├── utils/            # 工具函数
│   └── types/            # ts类型
├── preload/              # 预加载脚本（桥接层）
│   └── api/              # 暴露给渲染进程的api
├── renderer/             # 渲染进程（Web层）
│   └── src/
│       ├── api/          # 请求api
│       ├── assets/       # 静态资源
│       ├── layout/       # 页面布局
│       ├── router/       # 页面路由
│       ├── views/        # 页面
│       ├── utils/        # 工具函数
│       └── types/        # ts类型
└── shared/               # 主 / 渲染共享（共享层）
    └── types/            # ts类型
```

## 规范（重点查看，必需遵守）

### 通用规范

1. 目录/文件命名使用小驼峰命名法；前端.vue文件除了index文件，其他文件名使用大驼峰命名法；前端路由path/name，vue组件名称都使用小驼峰
2. 所有层级的目录代码，都要参考基础目录来组织结构
3. 目录内哪些文件能被访问，文件能访问哪些目录，取决与目录的作用分类与范围分类
4. ts类型中：interface都加上`I`前缀，type都加上`T`前缀，enum都加上`E`前缀
5. 非箭头函数参数类型和返回类型必须声明
6. 改任意代码时，如果该目录下当前层有目录`doc`，必需先读取`doc`目录下的`index.md`文件，并遵循其中的约定

### 注释规范

#### 文件头注释

```ts
/**
 * @file <文件中文名>
 * @description <说明字段：一句话讲清职责，复杂文件可换行续写约定 / 注意点>
 * @see <文档链接>（可选：模块沉淀了设计文档 / 有关联文档时填写，如 docs/design/release.md）
 */
```

#### 函数注释

```ts
/**
 * 获取发版配置
 * @param projectName 项目名称；为空时返回 null
 * @returns 发版配置数据
 */
export function fetchReleaseConfig(projectName: string): ReleaseConfig | null
```

#### 变量注释

单行注释使用 `//`：

```ts
// OSS 根路径
const ossRootPath = ''
```

多行注释使用 `/** */`：

```ts
/**
 * OSS 根路径
 * 不包含 bucket 部分
 */
const ossRootPath = ''
```
