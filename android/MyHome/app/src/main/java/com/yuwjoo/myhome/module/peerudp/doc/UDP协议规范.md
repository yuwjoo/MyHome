# UDP 协议规范

## 1. 帧结构

```
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│   Byte 0-1   │    Byte 2    │   Byte 3-4   │    Byte 5    │   Byte 6-7   │   Byte 8-9   │Byte 10 ~ 1471│
│    Magic     │     Type     │    SeqNum    │    Flags     │    PayLen    │    CRC16     │   Payload    │
│   2 bytes    │    1 byte    │   2 bytes    │    1 byte    │   2 bytes    │   2 bytes    │ ≤1462 bytes  │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
◄───────────────────────────────────────帧头=10字节───────────────────────────────────────►
◄────────────────────────────────────────10字节<=完整帧<=1472字节────────────────────────────────────────►
```

| 偏移  | 字节  | 字段            | 说明                                                                  |
| :---: | :---: | --------------- | --------------------------------------------------------------------- |
|   0   |   2   | **Magic**       | 协议魔数，固定 `0x59 0x48`（ASCII `YH`）                              |
|   2   |   1   | **Type**        | 消息类型，见 [消息类型](#消息类型)                                    |
|   3   |   2   | **SeqNum**      | 消息序号；无序消息固定为 `0x0000`                                     |
|   5   |   1   | **Flags**       | 标志位，见 [标志位](#标志位)                                          |
|   6   |   2   | **Payload Len** | 负载字节数，空负载为 `0x0000`                                         |
|   8   |   2   | **CRC16**       | 校验值，范围 = 帧头前 8 字节（Byte 0-7，不含 CRC 自身）+ 全部 Payload |
|  10   | ≤1462 | **Payload**     | 负载数据，单帧负载上限 1462 字节                                      |

## 消息类型

|   分类   |    Type     | 名称      | 收发方式  | 收发顺序  | 说明                                                                         |
| :------: | :---------: | --------- | :-------: | :-------: | ---------------------------------------------------------------------------- |
| **系统** |   `0x01`    | Heartbeat |   广播    |   无序    | 设备心跳消息                                                                 |
|          |   `0x02`    | Offline   |   广播    |   无序    | 设备离线消息                                                                 |
|          |   `0x03`    | Call      | 广播/单播 |   无序    | 发起呼叫，发送自身设备信息，期望收到回应设备信息，携带 [设备信息](#设备信息) |
|          |   `0x04`    | Answer    | 广播/单播 |   无序    | 发起回应，发送自身设备信息，携带 [设备信息](#设备信息)                       |
|          |   `0x05`    | Ack       |   单播    |   无序    | 消息确认应答，负载见 [Ack 负载](#ack-负载)                                   |
|          | `0x06-0x0F` | 保留      |     —     |     —     | —                                                                            |
| **业务** |   `0x10`    | Json      | 广播/单播 | 有序/无序 | JSON 消息                                                                    |
|          |   `0x11`    | Raw       |   单播    | 有序/无序 | 原始消息                                                                     |
|          | `0x12-0xEF` | 保留      |     —     |     —     | —                                                                            |
|          | `0xF0-0xFF` | 保留      |     —     |     —     | —                                                                            |

## 设备信息

| JSON 字段           | 类型          | 说明                                          |
| ------------------- | ------------- | --------------------------------------------- |
| `deviceName`        | string        | 设备名称                                      |
| `abilities`         | array<string> | 设备能力列表，如 `"topic:xxx"`、`"skill:xxx"` |
| `heartbeatInterval` | number        | 心跳发送间隔（毫秒）                          |
| `heartbeatTimeout`  | number        | 心跳过期间隔（毫秒）                          |

示例：

```json
{
  "deviceName": "living-room-light",
  "abilities": ["topic:light", "skill:brightness"],
  "heartbeatInterval": 5000,
  "heartbeatTimeout": 15000
}
```

## 标志位

|  Bit  | 名称        | 说明                                                                                               |
| :---: | ----------- | -------------------------------------------------------------------------------------------------- |
|   0   | **Ordered** | `0` 无序（立即发送、并行处理、不保证送达、可能重复）；`1` 有序（逐条发送、等待确认、不重复不丢包） |
|  1-7  | 保留        | 必须为 0                                                                                           |

## Ack 负载

Ack 的 Payload 为 4 字节定长二进制：

| 字段        | 字节  | 说明                                                                                      |
| ----------- | :---: | ----------------------------------------------------------------------------------------- |
| **AckSeq**  |  0-1  | 被确认的消息序号                                                                          |
| **RecvSeq** |  2-3  | 接收方当前允许接收的有序消息序，若 `RecvSeq == AckSeq` 表示该 AckSeq 对应消息已被正常消费 |
